# Guide to writing the plain-language explanations

Generated by `python -m stratum explanations --guide`. **Do not edit.** It lists, for each category in `resources/explanations.yaml`, the technical facts an explanation must be consistent with, the decisions that govern it, and the WP2 synthetic fixtures in which it occurs. The explanations themselves are in `resources/explanations.yaml` (D-075).

Each explanation should answer the same three questions:

1. What happened, in words a reader with no statistics training understands?
2. What can, and what cannot, be concluded from the experiment because of it?
3. What can the experimenter do next?

The report always prints the technical detail beside the explanation, so the explanation does not need to repeat numbers.

## WP2 evidence code: warning

### `missing_sites_exception`

- **Technical fact:** T2: only lowest-level, declared-exchangeable sites are missing and every higher unit is present; the narrow exception applies (unit-mean analysis, unequal precision).
- **Governing decisions:** D-016, D-021, D-022, D-028, D-043, D-047
- **Occurs in fixtures:** MISS-01, MISS-07, MISS-18

### `aliased_components`

- **Technical fact:** T2/T3: two model terms partition the observations identically; only their combined component can be reported.
- **Governing decisions:** D-046, D-054
- **Occurs in fixtures:** MISS-15, ALIAS-03

### `nuisance_unit_unique`

- **Technical fact:** A recorded nuisance factor each of whose levels lies inside a single top-level unit (e.g. a different day for every run): as a category it cannot be separated from unit-to-unit variation; it is neither adjusted for nor called confounding or aliasing.
- **Governing decisions:** D-045, D-053
- **Occurs in fixtures:** ALIAS-05

### `brown_forsythe`

- **Technical fact:** Median-centered Brown-Forsythe test across treatment groups of unit means gives p < 0.05.
- **Governing decisions:** D-044, D-055
- **Occurs in fixtures:** DIAG-02, DIAG-05

### `sd_ratio`

- **Technical fact:** Largest-to-smallest treatment-group SD of unit means is >= 2.0, infinite, or undefined.
- **Governing decisions:** D-044, D-055
- **Occurs in fixtures:** DIAG-02, DIAG-05

### `studentized_residual`

- **Technical fact:** Some externally studentized residual in a diagnosed stratum has absolute value > 3.
- **Governing decisions:** D-044, D-055
- **Occurs in fixtures:** DIAG-03, T3-05

## WP4 report caveat: caveat

### `assignment_not_randomized`

- **Technical fact:** A compared factor's assignment is declared systematic, not_stated or inherent. The F test and intervals are computed the same way; what differs is whether a difference can be attributed to the factor itself. Does not change the evidence decision (D-039, D-075).
- **Governing decisions:** D-039, D-075
- **Occurs in fixtures:** HIER-01, CONS-01, REP-01, MISS-01, MISS-05, MISS-07, MISS-13, MISS-18, CONF-01, CONF-02, CONF-06, CONF-07, ALIAS-01, ALIAS-02, ALIAS-03, ALIAS-05, DIAG-01, DIAG-02, DIAG-03, DIAG-04, DIAG-05, T3-01, T3-05, BLK-01

### `boundary_fit`

- **Technical fact:** A method-of-moments variance component is negative (reported as negative, then truncated at 0), or a REML component is exactly 0 because adjacent strata were pooled (brief Section 5.1; D-064, D-066).
- **Governing decisions:** D-066, D-075
- **Occurs in fixtures:** none (exercised by unit tests only)

### `degenerate_fit`

- **Technical fact:** An error mean square is exactly 0, so an F statistic with it as denominator is not defined (D-066).
- **Governing decisions:** D-066, D-075
- **Occurs in fixtures:** none (exercised by unit tests only)
