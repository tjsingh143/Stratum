# Scenario S1: chamber confounding (SYNTHETIC)

`output/results.json` or `output/comparison.json`. The data are synthetic and deliberately

varies.

## What the experiment appears to ask

Does the modified recipe change the response compared with the standard recipe? Three runs
of each recipe were processed, with three wafers per run and five sites per wafer, so the
comparison rests on 45 measurements per recipe.
The raw averages are 100 (standard) and
96 (modified), a raw difference of
-4. That number is descriptive only; it is not an estimate
Stratum supports.

## What the design actually supports

Nothing about the recipe. Every standard run was processed in chamber A and every modified
run in chamber B. A recipe difference and a chamber difference would produce exactly the
same data, so the recipe comparison is not estimable once chamber is taken into account.
Stratum refuses it (`complete_confounding`) and produces no estimate, test or interval. The
data were built with a recipe effect of zero and a chamber offset of -4, so in this
synthetic case the apparent difference is entirely the chamber.

## Why more measurements cannot fix it

The comparison is between runs, and there are 3
runs per recipe, all of one recipe in one chamber. Wafers and sites add measurements inside
those runs, but no measurement of either recipe in the other chamber. As the report's
technical detail puts it, more measurements below the run level cannot restore that missing
information. Adding sites makes the chamber difference more precisely measured; it never
separates it from the recipe.

## The proposed design

Stratum proposes a crossed, randomized assignment:
4 runs per recipe
(1 more than the declared
3, so that both recipes
appear equally often in both chambers),
2 runs of each recipe in each chamber,
8 runs in all, in a random order within
each chamber. The revised declaration matches T2 with chamber as a block, and the planned
layout passes Stratum's exact estimability check.

That design would estimate the recipe difference adjusted for chamber, tested against
run-to-run variation within a chamber on (1,
5) degrees of freedom. Using the
run-to-run variation the current data do show (within each chamber, on
4 degrees of freedom), its
expected standard error is 0.7071 (95% interval
0.4237 to
2.032), so a 95% interval for the
recipe effect would be expected to extend about
1.818 either side of the
estimate. That assumes chambers shift the response by the same amount for both recipes.

## What to conclude

From these data: nothing about the recipe. The observed difference may be the recipe, the
chamber, or both, and no analysis of these data can say which. To learn about the recipe,
run it in both chambers, as proposed.
