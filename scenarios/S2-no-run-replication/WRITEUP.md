## What the design actually supports

No test of the anneal. The anneal was applied to whole runs, so runs are the units that
received it, and there is one run per anneal. Two runs always differ somewhat, for reasons
that have nothing to do with the anneal, and with one run per anneal there is no way to see
how large that run-to-run difference is. Stratum therefore refuses the declaration
(`replication`, condition T2.replicated) before any analysis. The 108 measurements do not
become replicates of the anneal: every wafer and site of a run shares that run's conditions.
