### extra check (semiconductor.reml.minus2_restricted_loglik), class ITERATIVE

- Quantity: -
- Reference: 72.8312048136 (r_outputs, semiconductor/lmer_reml/reml_criterion)
- Stratum: 50.6504950357
- abs(difference) 22.1807 against tolerance 0.00728312
- Note from the frozen map: lme4's REMLcrit is -2 x the restricted log-likelihood; the convention is named, and any constant offset is reported rather than absorbed

**Explanation (computed, not asserted).** The reference exceeds Stratum's value by exactly 22.1807097779, which equals (N - p) * log 2 = 22.1807097779 on this design (agreement: yes). Stratum reports the standard restricted log-likelihood: -2 log L_R = (N - p) log(2 pi) + sum_k [ df_k log lambda_k + SS_k / lambda_k ] + log det(X'X), the standard restricted log-likelihood (Harville 1977). The last term is an additive constant that depends on how the fixed effects are parameterised, so a REML log-likelihood is comparable only between fits that share one. X here is the full-rank indicator parameterisation named in `fixed_parameterization`. The form without that term is also reported, and any offset against a package's printed value is reported rather than absorbed (D-064).

Stratum's restricted log-likelihood is checked against the textbook definition (Harville 1977), in exact rational linear algebra on the full covariance matrix, in tests/test_wp3_analysis.py for all three templates; and nlme's printed Oxide value agrees with Stratum to better than 1e-8 (same test file and the Oxide row above). A constant offset cannot affect any variance component, test, interval or degree of freedom. Recorded in DECISIONS.md D-070.
